# Contributing

Thanks for helping improve this course!

1. **Fork** the repository and clone your fork
2. Create a branch: `git switch -c docs/<topic>`
3. Edit or add notes in the matching folder (keep the numbered structure)
4. Follow [commit message conventions](09-Best-Practices/Commit-Messages.md), e.g. `docs: add git bisect note`
5. Rebuild the PDF if you changed notes: `bash scripts/build_pdf.sh`
6. Push and open a **pull request** describing your change

Found a mistake? Open an [issue](https://github.com/feroz-afm/git-github-full-course/issues).
