# Learning Path – How a New User Should Learn Git & GitHub

Never used Git before? Follow this **14-day plan** (about 1 hour per day). Read the note, type every command
yourself, then do the matching exercise.

| Day | Read | Practise |
|---|---|---|
| 1 | [Version Control](01-Introduction/Version-Control-System.md), [What is Git](01-Introduction/What-is-Git.md), [What is GitHub](01-Introduction/What-is-GitHub.md) | Create a GitHub account, enable 2FA |
| 2 | [Installation](02-Installation/Windows.md) (or macOS / Linux), [git config](03-Git-Basics/Git-Config.md) | Install Git and set name + email |
| 3 | [git init](03-Git-Basics/Git-Init.md), [git status](03-Git-Basics/Git-Status.md), [git add](03-Git-Basics/Git-Add.md), [git commit](03-Git-Basics/Git-Commit.md) | Exercises 1–2 |
| 4 | [git log](03-Git-Basics/Git-Log.md), [git diff](03-Git-Basics/Git-Diff.md), [.gitignore](03-Git-Basics/Gitignore.md) | Exercises 3–5 |
| 5 | [Branches](04-Branching/Git-Branch.md), [Merge](04-Branching/Git-Merge.md) | Exercise 6 |
| 6 | [Merge conflicts](04-Branching/Merge-Conflicts.md) | Exercises 7–8 |
| 7 | [Remotes](05-Remote-Git/Remote.md), [clone / push / pull / fetch](05-Remote-Git/Clone-Push-Pull-Fetch.md) | Exercises 9–10 |
| 8 | [Repositories](06-GitHub/Repository.md), [Fork & Pull Request](06-GitHub/Fork-and-Pull-Request.md) | Exercise 11 |
| 9 | [Issues & Projects](06-GitHub/Issues-and-Projects.md), [GitHub Pages](06-GitHub/GitHub-Pages.md) | Exercise 12 + start [Project 1](12-Projects/Project-1.md) |
| 10 | [Undo changes](07-Advanced-Git/Undo-Changes.md), [Stash](07-Advanced-Git/Stash.md) | Exercises 13 & 16 |
| 11 | [Rebase](07-Advanced-Git/Rebase.md), [Tags](07-Advanced-Git/Tags.md), [Cherry-pick](07-Advanced-Git/Cherry-Pick.md) | Exercises 14–15 |
| 12 | [GitHub Actions](08-GitHub-Actions/Introduction.md), [First workflow](08-GitHub-Actions/First-Workflow.md) | Add CI to Project 1 |
| 13 | [Commit messages](09-Best-Practices/Commit-Messages.md), [Branching strategy](09-Best-Practices/Branching-Strategy.md) | [Project 2](12-Projects/Project-2-Team-Collaboration.md) with friends |
| 14 | [Interview questions](10-Interview-Questions/Beginner.md) ([advanced](10-Interview-Questions/Advanced.md)), [Cheat sheet](13-Cheat-Sheet/Git-Cheat-Sheet.md) | Revise, answer questions aloud |

## Tips
- **Type, don't copy.** Muscle memory matters.
- Break things on purpose in a practice repo – that's how you learn to fix them.
- Run `git status` all the time.
- Prefer reading everything offline? Download the [PDF](pdf/Git-GitHub-Full-Course.pdf).
