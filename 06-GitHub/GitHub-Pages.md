# GitHub Pages – Free website hosting

1. Put an `index.html` (or a static site) in a repository
2. **Settings → Pages**
3. Source: **Deploy from a branch**, branch `main`, folder `/ (root)` or `/docs`
4. Save – the site appears at `https://<username>.github.io/<repo>/`

## Personal site
Name the repository **`<username>.github.io`** → it is served at `https://<username>.github.io`.

Great for portfolios, project demos and documentation.
