# GitHub Issues & Projects

## Issues
Use issues for bugs, feature ideas and tasks.
- Clear title, steps to reproduce, expected vs actual result
- **Labels** (`bug`, `enhancement`, `good first issue`), **assignees**, **milestones**
- Close automatically from a commit or PR: `Fixes #23`, `Closes #23`

## Projects
A **Project** is a board or table that tracks issues and PRs:
`Todo → In progress → Done`

Create one from your profile or organisation → **Projects → New project**, then add issues to it.

## Discussions
Turn on **Discussions** (Settings → Features) for Q&A and community conversations. In the **Q&A** category the
asker can mark an answer as accepted.
