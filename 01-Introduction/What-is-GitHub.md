# What is GitHub?

**GitHub** is a cloud platform for hosting Git repositories. It adds collaboration tools on top of Git.

## What you can do on GitHub
| Feature | Use |
|---|---|
| Repositories | Store code online, public or private |
| Pull Requests | Propose changes and review code before merging |
| Issues | Track bugs, tasks and ideas |
| Actions | Automate tests, builds and deployments (CI/CD) |
| Pages | Host a free static website from a repository |
| Projects | Kanban boards to plan work |
| Profile | Show your work, contribution graph and achievements |

## Git vs GitHub
| Git | GitHub |
|---|---|
| Software installed on your computer | Website / cloud service |
| Tracks changes locally | Hosts repositories online |
| Works offline | Needs internet |
| Command line tool | Web interface + APIs |

## Alternatives
GitLab, Bitbucket, Azure DevOps, Gitea — they all use Git underneath.

## Create your account
1. Go to <https://github.com/signup>
2. Choose a professional username (it becomes `github.com/<username>`)
3. Verify your email and enable **two-factor authentication** (Settings → Password and authentication)
