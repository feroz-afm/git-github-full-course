# GitHub Repositories

## Create a repository
1. Click **+** → **New repository**
2. Name it (lowercase, hyphens: `my-portfolio`)
3. Add a description, choose **Public** or **Private**
4. Optionally add a README, `.gitignore` and license

## Files every good repository has
| File | Purpose |
|---|---|
| `README.md` | What the project is and how to use it |
| `LICENSE` | Who may use the code (MIT, Apache-2.0, …) |
| `.gitignore` | Files not to track |
| `CONTRIBUTING.md` | How others can help |
| `CHANGELOG.md` | What changed in each version |

## Repository settings worth knowing
- **About** (right side): description, website, topics → helps people find the repo
- **Settings → Branches**: protect `main` (require pull requests)
- **Settings → Collaborators**: invite teammates
- **Releases**: publish versions with downloadable files

## Your profile README
Create a repository with **the same name as your username** – its README appears on your profile page.
