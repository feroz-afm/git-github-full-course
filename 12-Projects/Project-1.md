# Project 1 – Personal Portfolio with GitHub Pages

**Goal:** practise the full Git + GitHub workflow while building something you can show.

## Steps
1. Create a repository `<username>.github.io`
2. Clone it and add `index.html` with your name, skills and projects
3. Commit with good messages: `feat: add hero section`, `style: add colors`
4. Create a branch `feature/projects`, add a projects section, open a PR and merge it
5. Enable **GitHub Pages** (Settings → Pages → `main` / root)
6. Visit `https://<username>.github.io`
7. Tag the first version: `git tag -a v1.0.0 -m "First version"` and push it

## Bonus
- Add a GitHub Actions workflow that checks your HTML
- Add a README with a screenshot
- Ask a friend to open a PR (fork workflow) with a suggestion
